pgr_hawickCircuits - Experimentell¶

pgr_hawickCircuits - Returnerar listan över kretsar som använder Hawick-kretsalgoritmen.

Beskrivning¶

Hawick Circuit algorithm, is published in 2008 by Ken Hawick and Heath A. James. This algorithm solves the problem of detecting and enumerating circuits in graphs.

Circuit enumeration in directed graphs, where circuits with parallel arcs are enumerated.

  • Each combination of parallel arcs is returned as a different circuit.

De viktigaste egenskaperna är:

  • Works for directed graphs.

  • Algoritmen matar ut de olika kretsar som finns i grafen.

  • The circuits are elementary: a vertex is not repeated within a circuit, except the starting vertex that closes the circuit.

  • When no initial vertices are given all circuits are in canonical order of the vertices insertion of the graph: A circuit with vertices u, v: u starting circuits containing v will not be listed on start_vid = v rows.

    • Different edge ordering gives different canonical ordering.

  • When start vertices are given, all circuits are returned for each requested vertex it contains, and the results are grouped by start_vid.

  • The graph passed to the algorithm discard parallel edges with higher costs.

  • Tidskomplexitet: \(O((V + E) (c + 1))\)

    • där \(|E|\) är antalet kanter i grafen,

    • where \(|V|\) is the number of vertices in the graph.

    • where \(|c|\) is the number of circuits in the graph.

Parametrar¶

Parameter

Typ

Beskrivning

Kanter SQL

TEXT

Kanter SQL enligt beskrivningen nedan.

start vid

ANY-INTEGER

A vertex of the circuits: - All the circuits that contain the vertex are returned. - When 0 all the circuits are returned in canonical order.

start vids

ARRAY[ ANY-INTEGER ] ``

Vertices of the circuits: for each requested vertex: - All the circuits that contain the vertex are returned: - When empty all the circuits are returned in canonical order.

Valfria parametrar¶

Parameter

Typ

Standard

Beskrivning

min_depth

BIGINT

1

Minimum number of vertices in a circuit. * Exclude 2 edge circuits by increasing this number.

max_depth

BIGINT

9223372036854775807

Maximum number of vertices in a circuit.

self_loops

BOOLEAN

true

  • When true self loops are included in the results.

  • When false self loops are excluded from the results.

  • Self loops are included or excluded regardless of min_depth and max_depth.

u_turn_on_edge

BOOLEAN

true

  • A u-turn on an edge is a 2 edge circuit that uses the same id on both directions of the edge.

  • When true: u-turns are part of the results.

  • When false: u-turns are discarded when the circuit can be formed with two different edges; a u-turn is kept when it is the only option, that is, when the two vertices are connected by a single edge.

  • Self loops are not affected.

The examples use the following table c_example, that represent a cul_de_sac where the exit is on vertex \(5\) and the vehicle is on vertex \(1\) but pointing at the wrong direction of the exit.

CREATE TABLE c_example (
  id BIGINT,
  source BIGINT,
  target BIGINT,
  cost FLOAT,
  reverse_cost FLOAT
);
CREATE TABLE
INSERT INTO c_example (id, source, target, cost, reverse_cost) VALUES
(1, 1, 2, 1,  1),
(2, 2, 3, 1,  1),
(3, 1, 3, 1, 1),
(4, 1, 3, 1.5, 1.7),
(5, 1, 4, 1,  1),
(6, 1, 5, 1, -1),
(7, 1, 1, 1, -1);
INSERT 0 7
