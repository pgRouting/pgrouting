Circuits - Family of Functions¶

The following functions work on circuits of directed graphs.

Experimental

Warning

Possible server crash

  • These functions might create a server crash

Warning

Experimental functions

  • They are not officially of the current release.

  • They likely will not be officially be part of the next release:

    • The functions might not make use of ANY-INTEGER and ANY-NUMERICAL

    • Name might change.

    • Signature might change.

    • Functionality might change.

    • pgTap tests might be missing.

    • Might need c/c++ review.

    • Documentation if any might need to be rewritten.

    • Might need a lot of feedback from the community.

  • pgr_hawickCircuits - Experimental - Hawick’s circuits algorithm.

Description¶

Parameters¶

Parameter

Type

Description

Edges SQL

TEXT

Edges SQL as described below.

start vid

ANY-INTEGER

A vertex of the circuits: - All the circuits that contain the vertex are returned. - When 0 all the circuits are returned in canonical order.

start vids

ARRAY[ ANY-INTEGER ]

Vertices of the circuits: for each requested vertex: - All the circuits that contain the vertex are returned: - When empty all the circuits are returned in canonical order.

Optional parameters¶

Parameter

Type

Default

Description

min_depth

BIGINT

1

Minimum number of vertices in a circuit. * Exclude 2 edge circuits by increasing this number.

max_depth

BIGINT

9223372036854775807

Maximum number of vertices in a circuit.

self_loops

BOOLEAN

true

  • When true self loops are included in the results.

  • When false self loops are excluded from the results.

  • Self loops are included or excluded regardless of min_depth and max_depth.

u_turn_on_edge

BOOLEAN

true

  • A u-turn on an edge is a 2 edge circuit that uses the same id on both directions of the edge.

  • When true: u-turns are part of the results.

  • When false: u-turns are discarded when the circuit can be formed with two different edges; a u-turn is kept when it is the only option, that is, when the two vertices are connected by a single edge.

  • Self loops are not affected.

Inner Queries¶

Edges SQL¶

Column

Type

Default

Description

id

ANY-INTEGER

Identifier of the edge.

source

ANY-INTEGER

Identifier of the first end point vertex of the edge.

target

ANY-INTEGER

Identifier of the second end point vertex of the edge.

cost

ANY-NUMERICAL

Weight of the edge (source, target)

reverse_cost

ANY-NUMERICAL

-1

Weight of the edge (target, source)

  • When negative: edge (target, source) does not exist, therefore it’s not part of the graph.

Where:

ANY-INTEGER:

SMALLINT, INTEGER, BIGINT

ANY-NUMERICAL:

SMALLINT, INTEGER, BIGINT, REAL, FLOAT

Result columns¶

Column

Type

Description

seq

INTEGER

Sequential value starting from 1

path_id

INTEGER

Id of the circuit starting from 1

depth

INTEGER

Relative position in the circuit. Has value 0 for the beginning of a circuit

start_vid

BIGINT

Identifier of the starting vertex of the circuit.

end_vid

BIGINT

Identifier of the ending vertex of the circuit.

pred

BIGINT

Identifier of the node that precedes node in the circuit.

  • When node is the first node of the circuit, it has the same value as node.

node

BIGINT

Identifier of the node in the path from a vid to next vid.

edge

BIGINT

Identifier of the edge used to arrive from pred to node. - -1 when \(depth = 0\).

cost

FLOAT

Cost to traverse from pred to node using edge. - 0 when \(depth = 0\).

agg_cost

FLOAT

Aggregate cost from start_vid to node.
